# Employee Attendance Tracker

## 📌 Introduction
Employee Attendance Tracker is an application designed to be used on a desktop computer and written using the programming languages Python and Tkinter.

## 🚀 Features
- Employee authentication
- Mark attendance
- Attendance records
- Data stored in Excel file
- Graphical user interface

## 🛠️ Tools Utilized
- Python
- Tkinter
- OpenPyXL
- Excel file

## ▶️ Executing the Application

Install the library:
```bash
pip install openpyxl
```
Run the project:
```bash
python main.py
```
